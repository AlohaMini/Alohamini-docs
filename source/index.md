# AlohaMini

开源双臂移动机器人，面向具身智能研究与教学。

从连接机器人开始，完成遥操作，再采集演示、训练策略。

## 还没有组装好？

标准 2 从 [硬件组装](assembly.md) 开始，准备材料和打印件后按图搭建。Pro 请先核对 [硬件配置](hardware-pro.md)。
