# AlohaMini 1 物料与装配

本页对应 **一代 SO-ARM100 / SO-ARM101 双臂机器人**。二代用户请使用 [AlohaMini 2 物料清单](bom.md) 与 [二代装配](assembly.md)。

## 1. 先核对采购范围

一代按移动底盘、计算与供电、双从臂、双主臂分别准备。原 BOM 的 Host/Client 表述前后混用，本手册统一使用 **Pi 机器人端 / PC 操作端**，按设备实际连接关系核对。

| 模块 | 主要物料 | 数量与说明 |
|---|---|---|
| 底盘与升降 | STS3215-C018 12V、1/345 舵机 | 4 只，用于三轮与升降 |
| 全向轮 | 约 100 mm / 4 英寸 | 3 只 |
| 底盘相机 | 720p、2.4 mm、36×36 mm | 3 只 |
| 升降轴承 | 4×13×5 mm | 8 个 |
| 可选轮轴轴承 | 12×18×4 mm | 3 个 |
| 双从臂 | 12V、1/345 STS3215 舵机 | 12 只，另有两块控制板、两路腕部相机 |
| 双主臂 | 原 BOM 简化为 1/147 舵机 | 12 只，需确认实物额定电压与机械臂版本 |
| 独立运行模块 | Pi 5、12V → 5V/5A 降压模块、屏幕 | 按是否脱离 PC 有线控制选配 |

原 BOM 中主臂舵机与电池标注的电压并不一致，不能据此直接确定供电。按采购套件、舵机铭牌和控制板允许电压确认接线。

紧固件完整数量、线材长度和采购链接见 [一代 BOM](upstream/hardware--alohamini1-docs-bom.md)。原价格是历史记录，购买前重新核对规格与数量。

## 2. 打印件准备

原资料记录的底盘打印尺寸至少约 **385 × 345 × 64 mm**。确认模型包围盒和打印机可用空间，不能使用二代分块底盘的打印要求代替。

| 打印文件组 | 数量 |
|---|---|
| `OB_Chassis_Bearing_Cover` | 3 |
| `OB_Chassis_Servo_Mount` | 3 |
| `OB_Chassis_Side_Panel` | 3 |
| `OB_Chassis_Wheel_Axle_Connector` | 3 |
| `OB_Chassis_Wheel_Guard` | 3 |
| `OB_Top_Camera_Back_Cover` | 2 |
| `OB_Chassis_Shaft_Sleeve_12_24` | 3 |
| `O_Chassis_Dowel_Pin_12_37` | 3 |
| 其他底盘文件 | 原清单各 1，按完整装配核对 |
| 两只从臂 `D_*` / `F_*` | 各文件 2 份 |
| 两只主臂 `D_*` / `L_*` | 各文件 2 份 |

底盘和机械臂使用各自的打印清单，避免把不同目录的“其他文件各一份”混在一起计算。

## 3. 舵机编号与总线

1. 每次只连接一只待设置舵机，在官方调试工具中识别型号与串口。
2. 底盘相关 ID 使用 8、9、10、11；实际轮位按 [一代装配照片](upstream/hardware--alohamini1-docs-hardware_assembly.md) 核对。
3. 使用 20 cm 舵机线连接 8、9、10，使用 90 cm 线连接 10 与 11。
4. 安装完成后再检查 ID、连接顺序、运动方向与线缆余量。

二代的轮位表和升降 STS3095 配置不能直接套用到一代。

## 4. 按模块装配

完整照片已保留在 [一代图文组装全文](upstream/hardware--alohamini1-docs-hardware_assembly.md)。按以下顺序边看照片边完成：

1. **舵机支架**：安装热熔螺母，固定舵机，装轮轴连接件；配合过紧时先检查打印公差。
2. **底盘轮组**：将支架固定到底板，安装全向轮；按实物确认M3×14 装配步骤与 BOM M3×12 表项的差异。
3. **可选轮轴支承**：装入轴承、销和套筒，再固定轴承盖。
4. **侧板与立柱**：安装嵌件，拼装四段主体立柱，确认垂直与牢固后进行后续装配。
5. **升降机构**：组装轴、齿轮、舵机支架和 T 形连接件，手动检查无干涉。
6. **相机与显示屏**：安装顶部、后方与前方相机，走内部线槽，再固定显示屏。
7. **机械臂**：分别按匹配的 SO-100 / SO-101 教程完成主从臂，固定双从臂到 T 形支架两侧。
8. **电源与控制板**：按原图确认底盘总线、左臂控制板、Pi 降压模块和双臂分电线的实际连接。
9. **走线与检查**：检查升降全行程、机械臂运动范围、接头应力和电源规格，再进入校准。

## 6. 装配后的软件流程

使用 [一代软件说明](legacy.md) 中的 `alohamini1` 与 `so-arm-5dof`。先完成设备发现、校准和单模块运动检查，再采集 16 维整机数据。

[一代旧软件入口全文](upstream/hardware--alohamini1-docs-software_setup.md) 已保留；其中外部入口和历史命令需要与当前统一软件版本对应。
