# 开始使用

选择实物型号，按一篇教程走完 **接线 → 安装 → 配置 → 校准 → 遥操作 → 首次录制**。

```{raw} html

</div>
```

:::{admonition} 不确定自己的型号？
:class: am-extra

- **标准 2**：3D 打印底盘，轮舵机型号为 STS3215。
- **2 Pro**：金属强化底盘，轮舵机型号为 STS3250。

以设备铭牌和套件清单为准。改装设备需核对具体配置，不能只凭外观判断。
:::

还在搭建标准 2？先完成 [硬件组装](assembly.md)，再回来开始使用。只有一套主从臂时，使用 [单臂教程](single-arm.md)。
