There are two ways to run **AlohaMini** with **LeRobot**:

## **Method 1 — For existing LeRobot users**
If you’re already familiar with LeRobot, simply copy the files from  
`alohamini/software` into your existing LeRobot workspace.  
Then follow the configuration and command-line examples in the repository:  
👉 **https://github.com/liyiteng/lerobot_alohamini**

## **Method 2 — Recommended for beginners**
If you’re new to LeRobot and haven’t set it up before, it’s easier to clone the integrated repository directly:  
👉 **https://github.com/liyiteng/lerobot_alohamini**

This repository bundles **LeRobot + AlohaMini** together, so no manual copying or path configuration is required.
